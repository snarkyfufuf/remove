# remove

A Python script I wrote to bulk-remove unwanted lines from text files.

## Overview

`remove.py` recursively scans a directory for `.txt` files and deletes any line containing a specified string. By default, it removes lines containing `Hello, World!`, which you can change in the script.

## Installation

```bash
git clone https://github.com/snarkyfufuf/remove.git
cd remove
```

Git is required. If you don't have it, see the [Git installation guide](https://github.com/git-guides/install-git).

## Usage

```bash
python remove.py
```
